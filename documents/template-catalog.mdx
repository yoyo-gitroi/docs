<Info>
**Reference page** · **Live source of truth:** sidebar **Documents** → **Templates** tab (`/documents/templates`), one template at `/documents/templates/{slug}` · **Roles:** Principal ✓ Operator ✓ can create documents from these templates; only a Principal (or Admin) can fork, edit, lock or deactivate a template · **Baseline:** what the repo seeds; your tenant may differ.
</Info>

Use this page to see which templates exist and jump to a template's detail entry. To decide which template a user's words map to, use [Choosing a template](/documents/choosing-a-template).

<Warning>
The database is canonical. Tenants can fork, rename, recategorise, deactivate and add templates at runtime, so this catalog is the **shipped baseline**, not your tenant's live list. Before you rely on a slug, title or field label, check it in sidebar **Documents** → **Templates**.
</Warning>

## Legend

- **Kind:** *Handlebars* = HTML template whose fields the assistant fills; *Handlebars + LLM chapters* = the LLM writes whole chapters (`employee-handbook` only); *PDF form* = the publisher's own PDF, values only; *Legacy authored* = fields plus LLM-written prose sections.
- **Scope:** `client` = the document is about a client; `tenant` = about your own firm. It is a badge in the catalog. The Document Assistant needs a bound client for **both**. Slack refuses `client`-scope templates.
- **Person to name:** the individual the request must name (employee, candidate, contractor). Employees are typed as free text; there is no employee picker.
- **Notes:** *Not on `/generate`* = the template exists only in the database, so the `/generate` page does not list it; use the Document Assistant or Documents → Templates.
