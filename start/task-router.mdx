<Info>
**Use:** match the user's request to a row, open the linked recipe, follow it · **Rows:** 645 recipes across 10 areas · **Risk tags:** see [Operating rules](/start/operating-rules#risk-classes-and-the-approval-policy)
</Info>

Each row is one recipe. The first column lists ways a user might phrase the request; match on meaning, not exact words. If two rows fit, prefer the one whose page matches the object the user named (document, case, client, campaign). If no row fits, use the sidebar map in [Global UI patterns](/start/global-ui) and [Roles and access](/start/roles-and-access) to find the area, then read that page's recipes.

`EXTERNAL` and `DESTRUCTIVE` rows always need human approval before the risky click, even when the user asked for the task directly.
